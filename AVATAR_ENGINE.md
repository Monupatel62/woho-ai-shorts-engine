# Advanced Human Avatar Engine

The Shorts Engine now has an optional presenter-avatar pipeline.

## Architecture

`Script -> Piper Voice -> Audio Timeline -> Face/Eye/Mouth/Body Tracking -> MuseTalk Lip Sync -> Dynamic Camera -> Captions -> Shorts Validation`

### Tracking

`scripts/avatar_track.py` records per-frame:

- face bounding box
- selected face landmarks
- eye openness / blink score
- mouth openness and width
- head reference points
- shoulders, elbows, wrists and hips
- audio RMS aligned to the video timeline

### Avatar backend

The production backend is designed around MuseTalk 1.5. MuseTalk accepts an input video and audio and regenerates the face region to match speech while retaining the source video's body motion and camera performance.

### Source video requirement

Use a presenter video that you own or have permission to use:

`E:\\AI-Shorts\\avatars\\presenter.mp4`

For the best result, record:

- vertical 9:16
- 1080p or higher
- one presenter
- face visible throughout
- eyes visible
- mouth visible
- upper body + hands visible
- stable lighting
- natural gestures
- clean background
- 30 fps

The body, eye behavior and camera performance come from the source footage; the mouth region is audio-driven by the avatar backend.

## Configuration

Keep `AVATAR_MODE=off` until the backend is installed and preflight passes.

Then set:

`AVATAR_MODE=musetalk`

First install the local tracking runtime:

`powershell -ExecutionPolicy Bypass -File .\\scripts\\install-avatar-tracking.ps1`

Then run the preflight:

`powershell -ExecutionPolicy Bypass -File .\\scripts\\avatar-preflight.ps1`

No video is generated by the preflight.

## Commercial-use note

The MuseTalk code and model are documented by the project as commercially usable, but its dependency stack has separate licenses. The engine therefore keeps the avatar backend optional and does not bundle third-party weights into this repository. Always verify the exact model/dependency licenses before monetized publishing.
